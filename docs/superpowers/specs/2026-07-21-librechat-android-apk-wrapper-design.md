# LibreChat Android APK Wrapper — Design

**Date:** 2026-07-21
**Status:** Approved

## Overview
Package the LibreChat frontend as a sideloadable Android APK for personal use, using a Capacitor WebView wrapper pointed at the live production deployment (https://librechat-i0xh.onrender.com). No changes to LibreChat's own source code.

## Goals
- Installable APK icon on the user's phone that opens LibreChat full-screen, no browser chrome.
- Session/login persists like a normal mobile browser tab.
- Native back-button and status-bar behavior.
- Zero changes to LibreChat's `/api`, `/client`, or `/packages/*` workspaces.

## Non-Goals (v1)
- Push notifications.
- Offline support / asset caching.
- Google Play Store distribution (personal sideload only).
- Release signing / Play App Signing.

## Architecture
- New `mobile/` folder at the repo root, containing a standalone Capacitor project with its own `package.json` — deliberately excluded from the repo's npm workspaces (root `package.json` lists `["api", "client", "packages/*"]` explicitly, so `mobile/` is naturally excluded already) so it can't interfere with the Turborepo build.
- `mobile/www/` must be created manually before running `npx cap add android` or `npx cap sync` — the Capacitor CLI does not create `webDir` for you, and `cap add`/`cap sync` will warn (and copy nothing) if it's missing. Create `mobile/www/index.html` as a minimal static placeholder (e.g. `<!DOCTYPE html><title>LibreChat</title>`) — it satisfies the CLI's webDir check and is never actually served, since `server.url` overrides it at runtime.
- capacitor.config (ts or json):
  - appId: com.southerngaragedoors.librechat
  - appName: LibreChat
  - webDir: www (placeholder dir, see `mobile/www/` note above — required by Capacitor tooling but unused at runtime)
  - server.url: https://librechat-i0xh.onrender.com
  - server.androidScheme: https
  - plugins.StatusBar: style Style.Dark, backgroundColor #171717, overlaysWebView false. **Desired visual outcome: light-colored status bar icons/text on the dark #171717 bar** (matching LibreChat's dark theme-color from client/index.html). In Capacitor's StatusBar plugin, `Style.Dark` renders *light* icon content (it means "styled for a dark background"), and `Style.Light` renders *dark* icon content — the enum names the background it's suited for, not the icon color it produces. Using `Style.Light` here would render dark icons against the dark #171717 background and make them unreadable; `Style.Dark` is the correct value and must not be swapped.
- npx cap add android generates the native Android Studio project under mobile/android.
- Git tracking policy for `mobile/`: `mobile/node_modules/` and `mobile/android/` are gitignored, the same as `node_modules` elsewhere in the repo — both are fully regenerable (`npm install` in `mobile/`, then `npx cap sync android`) from the tracked `mobile/package.json`, `mobile/capacitor.config.*`, and `mobile/www/`. Only the Capacitor project config and the `www/` placeholder are committed; the native Android Studio project is treated as a build artifact, not source.

## Components
- Icons/splash: generated via @capacitor/assets from LibreChat's existing client/public/assets/maskable-icon.png, so the app uses LibreChat's real branding without new artwork.
- Back button: no custom code needed — Capacitor Android's default BridgeActivity already navigates WebView history on back-press and exits the app at root.
- Status bar: configured declaratively via the plugins.StatusBar config block; applied natively at launch, no JS changes needed (the remote page's own JS is untouched).
- Splash screen: generated by the same `@capacitor/assets` run as the icons, passing `client/public/assets/maskable-icon.png` as the splash source (not a hand-derived separate asset) and letting the tool auto-center/pad it onto a solid `#171717` background (matching the StatusBar `backgroundColor` above) at the tool's default splash canvas size. Use a single splash asset — no separate light/dark variants — since `@capacitor/assets`' default splash generation only produces one set unless light/dark source images are explicitly supplied, and this app has no light theme mode to match.

## Data Flow
- WebView loads https://librechat-i0xh.onrender.com directly (same origin as a normal browser visit). Auth cookies/JWT persist through Capacitor's native WebView cookie store, so login state survives app restarts.
- No local dev server, no bundled web assets — the "web app" the APK ships is just the remote URL config.

## Error Handling
- Server unreachable / offline: default WebView error page (out of scope to build a custom offline page for v1, per non-goals).
- No app-content auto-update needed since it loads live from Render; the APK itself only needs rebuilding for native-shell changes (icon, splash, app id, Capacitor version bumps).

## Testing
- Debug-signed APK (Capacitor/Gradle's default debug keystore) — sufficient for personal sideloading, no release keystore needed for v1.
- Manual verification checklist (requires Android Studio + SDK, not available in this automated pass):
  1. npx cap sync android
  2. Open mobile/android in Android Studio
  3. Run on emulator or a physical device via USB debugging
  4. Verify: login persists, sending/receiving messages works, back button behaves correctly, app resumes correctly from background
  5. Build → Build APK(s) to produce the installable file, then sideload to phone

## Setup Prerequisite (one-time, outside repo scope)
- Install Android Studio (bundles JDK + SDK) on this machine — not yet installed as of 2026-07-21. Required before mobile/android can actually be built/run; the scaffold itself doesn't require it.

## Locked-In Decisions
- Android application ID: com.southerngaragedoors.librechat
- Distribution: personal sideload only, no Play Store
- Scope: bare wrapper only (no push, no offline) for v1
- StatusBar style is `Style.Dark` (produces light icons for the dark #171717 bar) — do not read the "Dark" name as "dark icons"
- `mobile/node_modules/` and `mobile/android/` are gitignored (regenerable build artifacts); only `mobile/package.json`, `mobile/capacitor.config.*`, and `mobile/www/` are committed
- Splash source is `maskable-icon.png` fed directly into `@capacitor/assets`, auto-centered/padded onto a solid `#171717` background — no separately hand-derived splash art, no light-mode variant
